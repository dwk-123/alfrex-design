# Legacy `.als-*` to shadcn map

Use this when reading or migrating legacy Alfrex markup. “Stock” means the
base-nova/Base UI source generated by shadcn. “Alfrex” means a component copied
from this skill's `assets/components/` directory.

| `.als-toast-viewport` | Stock Sonner `<Toaster position="bottom-right">`; do not hand-position individual toasts |

The legacy narrow-screen CSS stacked arbitrary grid cells using `data-label`.
For a migrated table, choose deliberately between horizontal scroll and a
separate mobile list/card rendering. Never squeeze columns until figures clip.

## Stock component conventions

- **Card:** always add a border and remove generated visual ring/shadow when the
  stock source's defaults differ: `border shadow-none ring-0`.
- **Table:** headers are uppercase 11px. Every operational number is
  `font-mono tabular-nums text-right`; never right-align prose.
- **Dialog:** only the backdrop/content floats, so modal shadow is allowed.
- **Sonner:** every mutation reports success or failure. Red is for the error
  state, not the generic toast container.
- **Select and DropdownMenu:** use stock Base UI sources. Do not recreate the
  legacy `.als-menu` or `.als-select` forks.
- **Tabs:** use for two to four lenses on one dataset, not primary navigation.
